# Git-Workflow

- `main`: produktionsnaher Stand.
- `develop`: Integrationsbranch.
- `feature/*`: neue Funktionen.
- `fix/*`: Fehlerbehebungen.
- `release/*`: Release-Vorbereitung.
- `hotfix/*`: schnelle Produktionskorrekturen.

Commit-Stil: Conventional Commits, z. B. `feat: add planner toolbar` oder `fix: handle export path`.
